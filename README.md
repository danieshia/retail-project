# retail-project

## Project Overview:
This is a transactional dataset that contains all the transactions occurring between 12/01/2009 and 12/09/2011 for a UK-based and registered non-store online retailer. The company mainly sells unique all-occasion gifts. Many customers of the company are wholesalers. For this project, I used MySQL, Python, and Tableau.


## Dataset Used: https://archive.ics.uci.edu/dataset/502/online+retail+ii
